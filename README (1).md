# AI Finance Controller

An AI-assisted finance co-pilot that automatically reconciles a company's
internal ledger against its bank statement, flags anomalies (outliers,
duplicate payments, unexplained bank charges), and generates plain-language
recommendations — all in an interactive Streamlit dashboard.

## Features

- **Automated reconciliation** — matches ledger entries to bank statement
  entries using vendor-name similarity, date proximity, and amount tolerance.
- **Anomaly detection** — flags statistically unusual transactions and
  possible duplicate payments.
- **AI recommendations** — rule-based plain-English insights summarizing
  reconciliation issues (swap in an LLM call later for richer commentary).
- **Spend dashboard** — category breakdown, top vendors, weekly spend trend.

## Project structure

```
ai-finance-controller/
├── App.py                   # Main Streamlit app (entry point)
├── reco_engine.py            # Reconciliation + anomaly detection logic
├── generate_sample_data.py   # Creates demo ledger.csv / bank_statement.csv
├── ledger.csv                 # Sample company ledger
├── bank_statement.csv         # Sample bank statement
├── requirements.txt
└── README.md
```

## Run locally

```bash
pip install -r requirements.txt
streamlit run App.py
```

The app opens at `http://localhost:8501`. Use the sidebar to switch between
sample data and your own CSV uploads.

## Deploy on Streamlit Community Cloud (free)

1. Push this folder to a **public GitHub repository**.
2. Go to [share.streamlit.io/new](https://share.streamlit.io/new).
3. Choose **"Deploy a public app from GitHub"**.
4. Select your repo, branch `main`, and main file path `App.py`.
5. Click **Deploy**. Your app will be live at
   `https://<your-app-name>.streamlit.app` within a couple of minutes.

## Uploading your own data

Your CSVs should roughly follow this shape:

**ledger.csv**
| txn_id | date | vendor | category | amount | type | recorded_by |
|---|---|---|---|---|---|---|

**bank_statement.csv**
| bank_ref | value_date | narration | debit_amount |
|---|---|---|---|

If your columns differ, you can either rename them before upload or adjust
`reco_engine.py` to match your schema.

## Notes

- Sample data (`ledger.csv`, `bank_statement.csv`) is synthetic and
  regenerated by `generate_sample_data.py` — safe to demo/share publicly.
- The recommendation engine is currently rule-based for reliability and
  zero API cost; it can be swapped for an LLM-backed summarizer (e.g. via
  the Anthropic API) for richer natural-language insights.
